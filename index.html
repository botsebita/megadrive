Conexión sencilla por códigoDesconectado

El Jugador 1 crea una sala y comparte un código corto. El Jugador 2 lo introduce; el emulador negocia la conexión automáticamente.

Código de sala------

Envía este código a tu amigo. Él lo introduce en el campo de arriba.

Las salas usan PeerJS Cloud para intercambiar la información de conexión. El emulador usa la configuración STUN/TURN predeterminada de PeerJS; algunas redes pueden impedir la conexión.

Netplay experimental: puede haber retraso o desincronización. Algunas redes bloquean la conexión directa; todavía no incluye el sistema rollback de Dolphin.
